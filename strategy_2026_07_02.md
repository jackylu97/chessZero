## 3. Steering post-mortem (the 06-26/27 regression, resolved)

- `94b6388` (06-26) dropped search steering for the Leela formulation
  (on-policy + Syzygy value relabel + Gaviota DTM relabel). The covariate-shift
  measurement motivating it (95% in-dist on-policy vs 43% steered) was real and
  the change was correct **as far as policy-target purity goes**.
- At matched steps there was NO steering advantage (steered `tb_value`
  0.58–0.66 @28k vs on-policy `leela_relabel`/`seed30` 0.64–0.68 @26k).
- **But steering had a second, unnoticed function: it was the last sustained
  decisive-outcome generator.** Buffer decisive fraction: steered s09 holds
  0.62–0.73 for 86k steps (win-vs-random climbs 0.50→0.84); every on-policy run
  erodes monotonically (leela 0.65→0.50, seed30 0.54→0.36, attn run 0.71→0.33
  with win-vs-random decaying 0.44→0.12). Decisive sources without steering:
  warmstart (annealed away by design), resignation (needs a calibrated value
  head — self-limiting circularity; FP=1.0 on holdout in the attn run), real
  mates (need skill the model lacks). Once warmstart fades, the V^π≈draw basin
  reasserts.
- Confounds in the 06-27 collapse: the resign color-parity bug (fixed 9615723)
  corrupted seeded-game outcomes 06-26→06-30; the s100 family ran seed_frac=1.0
  (starved midgame); every post-drop run was killed at 10–30k while s09 got a
  stable 86k. Steering is exonerated as "the" regression AND rejected as a
  teaching mechanism. What must be replaced is the decisive-outcome supply.

## 4. The two new mechanisms

### TB anchor (`--tb-anchor-path/games/interval`, `scripts/gen_tb_anchor_games.py`)
Tablebase-optimal demonstration games from decisive ≤5-man seeds
(`data/endgame_seeds_train.txt`; 15% holdout untouched), both sides TB-optimal
to mate, per-ply targets = the exact deferred-relabel semantics (soft
win-preserving DTZ policy, STM TB value, Gaviota |DTM| moves-left). Stored as
v2 compact shards (no observations — rebuilt by the canonical replay on load,
eliminating encoder-drift risk); injected into the ROLLING buffer 64 games /
256 steps, cycling the 20k-game archive forever. This is the supervised-proxy
loss (KQvK 0.91) as a persistent production anchor — the direct TB→policy
channel. Never annealed (the qratio run showed what a draining anchor does).
`game_outcome` uses ply-0-mover POV (see §6).

### TB rollout fill (`--tb-rollout-fill`, `_apply_tb_rollout_fill`)
Win adjudication by demonstration (the user's formulation): a NON-seeded game
whose first decisive in-TB ply contradicts its played outcome is truncated
there and finished with TB-optimal play by both sides.
- `game_outcome` becomes the TRUE result for the WHOLE trajectory — decisive z
  for the pre-TB middlegame plies, which the per-ply value relabel structurally
  cannot reach (a won game that shuffled to a draw kept z=draw on plies 0..69).
- The appended tail is an on-distribution conversion demonstration (positions
  the model's own play reached) — no search bias, no covariate shift.
- Seeded games are exempt (they START decisive-in-TB; filling would delete the
  practice data at ply 0 — and the anchor already supplies pure demos).
- Filled games skip resignation (`h.tb_filled`); games whose outcome already
  matches the verdict are left untouched (on-policy conversions are gold).
- vs resignation: resignation = the model's own value head (subjective,
  circular, needs the FP holdout); adjudication = ground truth (exact,
  unconditional, cannot decay). They stack: TB range vs hopeless non-TB.

## 5. The min-DTZ repetition trap (found by test, fixed everywhere)

Naive "minimize child DTZ" play NEVER converts positions like K+3P vs K at
cur_dtz=1: after a king shuffle the child's DTZ stays 2 (the pawn push "remains
available"), which min-DTZ prefers over the push's child DTZ 3 → fivefold
repetition. DTZ counts to the next ZEROING event; the correct rank is
**zeroing-aware**: a win-keeping zeroing move completes the phase NOW (rank 0),
a non-zeroing move completes it in child-DTZ more plies. Fixed in:
- `tb_playout._pick_move` (winner: mate-now > zeroing > min child DTZ;
  loser: max-DTZ resistance), plus a 50-move guard (clock + DTZ ≤ 99) and a
  must-end-in-mate assertion (else the game is skipped, never stored).
- `syzygy_probe._classify` / `_classify_board` (kept identical): the soft
  DTZ-softmax POLICY TARGET previously put its mass on the shuffle move at
  such positions — i.e. the relabel target itself taught the trap.

## 6. Latent convention hazard (documented, currently masked)

`make_target._outcome_onehot` assumes ply 0 = white (`ply % 2 == 0`), while the
GPU path stores `game_outcome` white-POV. For black-to-move seeded games these
diverge → inverted legacy value targets. Currently masked because seeded games
are 100% in-TB and `tb_value_weight=1.0` fully replaces their value targets.
The anchor generator therefore stores outcomes in **ply-0-mover POV** (correct
under `_outcome_onehot` for any start color); the fill only touches standard-
start games where the conventions coincide. If tb_value_weight is ever lowered,
fix `_outcome_onehot` to derive the start side from `start_fen` first.

  held 0.72-0.78 (baseline eroding through 0.46), draw rate halved, fill steady
